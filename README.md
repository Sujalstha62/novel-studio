It's an app for my beloved novel writers. 
The moto for this app was to create a platform for writers. And as a write I myself never found proper application for my hobby - the ones I find had very limited features and too many subscriptions. 
It all fixes with this simple app. This not only provides a platform but has multiple useful features like -
- Grammar checking and correction.
- An AI integrated character and event recognition system that can help you track characters, plots, and events.
- Provided a visual map that connects everything together so you can see the involvement of each character in an event.
- Supports Drive backup and recovery.
- Multi-level directory that helps create any complex structure of the file.
- Contains multiple different export system.
And more features to be added in the future.
Everything is completely open sources and safe.
